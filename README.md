Система автоматической генерации и перевода субтитров для видеоматериалов.

Проект выполняет локальную обработку видео и объединяет автоматическое распознавание речи, машинный перевод и сегментацию субтитров с учетом ограничений читаемости и синтаксической целостности текста.

- автоматическое распознавание речи из видео;
- автоматический перевод субтитров;
- формирование субтитровых блоков;
- синтаксическая корректировка границ субтитров;
- корректировка таймингов с учетом скорости чтения;
- экспорт субтитров в формате SRT;
- генерация видео со встроенными субтитрами;
- локальная работа без использования облачных сервисов.
